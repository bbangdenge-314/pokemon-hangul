# 포켓몬 한글 따라쓰기 ✏️ (v3)

▶ **바로 놀기: https://bbangdenge-314.github.io/pokemon-hangul/**

휴대폰 브라우저에서 열고 "홈 화면에 추가"를 누르면 앱처럼 전체 화면으로 실행됩니다.

포켓몬 그림을 보고, 이름을 소리로 듣고, **손가락으로 이름을 쓰는** 5살 한글 놀이입니다.

- 설치 없이 브라우저에서 바로 실행되는 정적 사이트 (GitHub Pages)
- **1~9세대 포켓몬 45마리** — 도감에서 세대 배지(1세대~9세대)와 세대별 필터를 볼 수 있어요
- 글자를 다 쓰면 **손을 뗀 뒤 저절로** 정답 처리 (획을 긋는 중에는 절대 채점하지 않아요)
- **6단계**: 진한 글자 따라 쓰기 → 흐린 글자 → **가이드 없는 백지에 혼자 쓰기**
- 진행 상황은 브라우저(localStorage)에 저장됩니다

## 노는 방법

1. 포켓몬이 나오고 이름을 읽어 줍니다. 써 볼 글자는 노란 칸으로 표시돼요.
2. 칸 안의 글자 위를 손가락으로 따라 긋습니다. 굵은 크레파스 선이 그려져요.
3. 글자를 **끝까지 다 쓰고 손을 떼면**, 잠깐 뒤에 저절로 "짝짝짝!" 하고 다음 글자로 넘어갑니다.
   - 아직 덜 썼으면 채점하지 않고 기다립니다. 그림은 지우지 않아요. 이어서 더 쓰면 됩니다.
   - `다 썼어요!` 는 **확인용** 버튼입니다. 아직 부족하면 어디가 비었는지 노란 표시로 알려 주고,
     그림은 그대로 둡니다. (이 버튼을 여러 번 눌러도 통과하지 않아요 — 인식이 정확할 때만 통과)
   - `↺` 다시 쓰기, `🔊` 다시 듣기
4. 이름을 다 쓰면 포켓몬을 잡아 **나의 포켓몬 도감**에 담깁니다.

## 글자 인식 (정밀 채점)

글자 하나를 세 가지로 함께 봅니다. 하나라도 모자라면 통과하지 않습니다.

| 검사 | 내용 | 기준 |
| --- | --- | --- |
| 덮음(recall) | 가이드 글자의 잉크를 크레파스 선이 얼마나 덮었는지 (허용 폭 ≈ 글자칸 너비의 8%) | 70~74% (백지 단계 66~68%) |
| 구역(zone) | 글자 상자를 3×3으로 나눠, 잉크가 있는 구역을 모두 채웠는지 — 받침이나 모음을 통째로 빼면 걸립니다 | 구역마다 50~55% |
| 벗어남(precision) | 크레파스 선이 글자 허용 범위 **밖**에 얼마나 있는지 — 마구 낙서를 걸러냅니다 | 45% 이하 |

- 채점은 **손을 뗀 뒤 0.42초** 뒤에만 합니다. 다음 획을 그리기 시작하면 취소됩니다.
  (획 사이에 손을 떼도 글자 중간에 넘어가지 않아요)
- 5·6단계 백지 칸은 글자를 보여 주지 않고, 그림과 소리만으로 씁니다.
  막힐 때만 `💡 살짝 힌트` 로 글자 모양을 잠깐 볼 수 있고, 힌트를 쓰면 별이 줄어요.

## 단계 (쉬운 것 → 어려운 것)

| 단계 | 이름 | 가이드 | 쓰는 글자 | 예 |
| --- | --- | --- | --- | --- |
| 1 | 첫 글자 따라 쓰기 | 진한 회색 | 이름의 첫 글자 1개 | **피**카츄 · **꼬**부기 · **나**오하 |
| 2 | 두 글자 따라 쓰기 | 진한 회색 | 두 글자 이름 전체 | 마릴 · 빠모 · 푸린 · 야돈 |
| 3 | 세 글자 따라 쓰기 | 진한 회색 | 세 글자 이름 전체 | 파이리 · 아차모 · 수댕이 |
| 4 | 흐린 글자 따라 쓰기 | 아주 연한 흐림 | 세 글자 이름 전체 | 이브이 · 조로아 · 님피아 |
| 5 | 빈칸 혼자 쓰기 | 백지(한 글자) | 3~5글자 이름 중 빠진 한 글자 | 이상해**?** · 한카리아**?** · 따라**?** |
| 6 | 이름 전체 혼자 쓰기! | 백지(전체) | 이름 전체 | ?염버니? · ??루카리오?? |

각 단계는 포켓몬 6~7마리로 이루어져 있고, 앞 단계를 깨야 다음 단계가 열립니다.
5·6단계에는 `💡 살짝 힌트` 버튼이 있습니다.

## 보상

- 이름을 다 쓰면 그 포켓몬이 **도감**에 담깁니다 (도감 45마리 전부 잡을 수 있어요).
- 단계를 깨면 보상 포켓몬이 포켓볼에서 나옵니다
  (토게피 · 블래키 · 나무지기 · 가디안 · 팽도리 · 자시안).
- 별 3개가 기본이고, "다시 쓰기"나 힌트를 많이 쓰면 별이 줄어요.
- 모든 단계를 깨면 전설의 포켓몬 **뮤**가 찾아옵니다.

## 보호자 메뉴

홈/지도 화면의 `보호자` 버튼에서

- 소리 끄기 / 켜기
- 전체 단계 열기 (단계 잠금 해제)
- 진행 기록 지우기

## 개발

정적 파일만 있습니다. `index.html` 을 열거나 아무 정적 호스팅에 올리면 됩니다.

- `index.html` — 화면 뼈대
- `style.css` — 스타일
- `data.js` — 학습 데이터(1~9세대 포켓몬 45마리, 6단계 문제)
- `app.js` — 따라쓰기 캔버스, 정밀 인식(덮음·구역·벗어남), 채점 시점, 진행 로직, Web Audio 효과음, 한국어 TTS
- `build_standalone.py` — 위 파일들을 합쳐 `standalone.html` 한 파일로 만들기 (`python3 build_standalone.py`)
- `tests/run_tests.py` — Playwright 브라우저 자동 테스트 (`python3 tests/run_tests.py`)

포켓몬 이름·번호·세대는 [PokeAPI](https://pokeapi.co/) `pokemon-species` 의 한국어 명칭으로 확인했고,
이미지는 [PokeAPI 공식 아트워크 스프라이트](https://github.com/PokeAPI/sprites)를 사용합니다
(로드 실패 시 스프라이트 → 포켓볼 그림 순서로 대체).

주소 끝에 `#debug` 를 붙이면 `window.__trace` 로 칸 상태·채점 결과를 확인할 수 있는 테스트용 도우미가 켜집니다.

> v3에서 단계 구성이 바뀌어 진행 기록 키가 `pokemon-hangul-trace-v3` 로 새로 시작합니다.
