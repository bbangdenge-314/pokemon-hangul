# 포켓몬 한글 대모험 🎮

▶ **바로 놀기: https://bbangdenge-314.github.io/pokemon-hangul/**

휴대폰 브라우저에서 열고 "홈 화면에 추가"를 누르면 앱처럼 전체 화면으로 실행됩니다.

5살 어린이가 포켓몬을 잡으면서 한글을 배우는 웹 놀이입니다.

- 설치 없이 브라우저에서 바로 실행되는 정적 사이트 (GitHub Pages)
- 소리를 내어 읽어 주는 방식이라 글자를 몰라도 놀 수 있어요 (한국어 TTS)
- 진행 상황은 브라우저(localStorage)에 저장됩니다

## 단계

| 단계 | 이름 | 내용 |
| --- | --- | --- |
| 1 | 모음 친구들 | 소리를 듣고 ㅏ ㅑ ㅓ ㅕ ㅗ ㅛ ㅜ ㅠ 를 고르기 |
| 2 | 자음 탐험 | ㄱ ㄴ ㄷ ㄹ ㅁ ㅂ ㅅ ㅇ 의 첫소리 찾기 |
| 3 | 글자 합체! | 자음 + 모음이 만나 가, 노, 디 … 를 만들기 |
| 4 | 이름 첫 글자 | 포켓몬 이름을 듣고 첫 글자 고르기 |
| 5 | 이름 완성! | 포켓몬 이름의 빈칸 글자 채우기 |

## 보상

- 단계를 깨면 포켓몬을 잡아 **나의 포켓몬 도감**에 담깁니다 (단계별 보상 + 문제에서 만난 포켓몬).
- 실수 없이 깨면 별 3개, 1~2번 실수하면 별 2개, 그보다 많으면 별 1개.
- 모든 단계를 깨면 전설의 포켓몬 **뮤**가 찾아옵니다.

## 보호자 메뉴

홈/지도 화면의 `보호자` 버튼에서

- 소리 끄기 / 켜기
- 전체 단계 열기 (단계 잠금 해제)
- 진행 기록 지우기

## 개발

정적 파일만 있습니다. `index.html` 을 열거나 아무 정적 호스팅에 올리면 됩니다.

- `index.html` — 화면 뼈대
- `style.css` — 스타일
- `data.js` — 학습 데이터(단계·문제·포켓몬)
- `app.js` — 진행 로직, Web Audio 효과음, 한국어 TTS

포켓몬 이미지는 [PokeAPI 공식 아트워크 스프라이트](https://github.com/PokeAPI/sprites)를 사용하며, 로드에 실패하면 스프라이트 → 포켓볼 그림 순서로 대체됩니다.
