# 포켓몬 한글 따라쓰기 ✏️ (v4.1)

▶ **바로 놀기: https://bbangdenge-314.github.io/pokemon-hangul/**

휴대폰 브라우저에서 열고 "홈 화면에 추가"를 누르면 앱처럼 전체 화면으로 실행됩니다.

포켓몬 그림을 보고, 이름을 소리로 듣고, **손가락으로 이름을 쓰는** 5살 한글 놀이입니다.

- 설치 없이 브라우저에서 바로 실행되는 정적 사이트 (GitHub Pages)
- **전국도감 1~1025, 1~9세대 1,025마리 전체** — 도감에서 세대별로 보고, 이름·번호로 찾을 수 있어요
- 글자를 다 쓰면 **손을 뗀 뒤 저절로** 정답 처리 (획을 긋는 중에는 절대 채점하지 않아요)
- 포획하면 그 포켓몬의 **울음소리**가 나요 (안 되면 한국어 목소리로 "○○! 잡았다!")
- **6단계**: 진한 글자 따라 쓰기 → 흐린 글자 → **가이드 없는 백지에 혼자 쓰기**
- 진행 상황은 브라우저(localStorage)에 저장됩니다

## 노는 방법

1. 세대를 고르고(전체 / 1~9세대) 단계를 시작하면 포켓몬이 나오고 이름을 읽어 줍니다.
   써 볼 글자는 노란 칸으로 표시돼요. 포켓몬 그림을 누르면 울음소리를 들을 수 있어요.
2. 칸 안의 글자 위를 손가락으로 따라 긋습니다. 굵은 크레파스 선이 그려져요.
3. 글자를 **끝까지 다 쓰고 손을 떼면**, 잠깐 뒤에 저절로 "짝짝짝!" 하고 다음 글자로 넘어갑니다.
   - 아직 덜 썼으면 채점하지 않고 기다립니다. 그림은 지우지 않아요. 이어서 더 쓰면 됩니다.
   - `다 썼어요!` 는 **확인용** 버튼입니다. 아직 부족하면 어디가 비었는지 노란 표시로 알려 주고,
     그림은 그대로 둡니다. (여러 번 눌러도 통과하지 않아요 — 인식이 정확할 때만 통과)
   - `↺` 다시 쓰기, `🔊` 다시 듣기
4. 이름을 다 쓰면 포켓몬이 **울음소리를 내며** 나의 포켓몬 도감에 담깁니다.

| 1세대 관동 | 151 | 6세대 칼로스 | 72 |
| 2세대 성도 | 100 | 7세대 알로라 | 88 |
| 3세대 호연 | 135 | 8세대 가라르 | 96 |

- 지도 화면 위쪽의 `전체 / 1세대 ~ 9세대` 칩으로 그 세대 포켓몬만 나오게 할 수 있습니다.
  고른 세대는 저장되고, 단계 카드에 "몇 마리 중 몇 마리"가 나와요. 세대를 고르면 문제 화면 위에도 표시됩니다.
- `전체`로 두면 **한 단계(한 라운드) 안에서 1~9세대가 골고루 섞여** 나옵니다.
  세대 순서를 매번 무작위로 섞고 세대마다 한 마리씩 번갈아 뽑아서(후보가 많은 세대는 조금 더 자주),
  한 세대에 몰리지 않고 매번 다른 조합이 나와요. (2026-11-18 수정 — 예전에는 세대 칩이 도감 필터와
  엮여 있어 한 세대만 계속 나오는 것처럼 보였습니다.)
- 문제는 미리 정해 두지 않고 **그때그때 뽑습니다**. 아직 못 잡은 포켓몬을 먼저 골라서,
  같은 단계를 다시 해도 새로운 포켓몬을 만나게 됩니다. (1,025마리 모두 어느 단계에서는 나옵니다)

## 단계

| 단계 | 이름 | 가이드 | 쓰는 글자 | 나올 수 있는 포켓몬 |
| --- | --- | --- | --- | --- |
| 1 | 첫 글자 따라 쓰기 | 진한 글자 | 이름의 첫 글자 1개 | 이름이 두 글자 이상 (1,023마리) |
| 2 | 짧은 이름 따라 쓰기 | 진한 글자 | 한두 글자 이름 전체 | 88마리 |
| 3 | 세 글자 따라 쓰기 | 진한 글자 | 세 글자 이름 전체 | 530마리 |
| 4 | 흐린 글자 따라 쓰기 | 아주 연한 흐림 | 세·네 글자 이름 전체 | 856마리 |
| 5 | 빈칸 혼자 쓰기 | 백지(한 글자) | 이름에서 빠진 한 글자 | 937마리 |
| 6 | 이름 전체 혼자 쓰기! | 백지(전체) | 두세 글자 이름 전체 | 616마리 |

- 단계마다 4~6문제를 풀면 단계를 깨고, 앞 단계를 깨야 다음 단계가 열립니다.
- 5·6단계에는 `💡 살짝 힌트` 가 있어 글자 모양을 잠깐 볼 수 있어요 (힌트를 쓰면 별이 줄어요).

## 글자 인식 (정밀 채점)

글자 하나를 세 가지로 함께 봅니다. 하나라도 모자라면 통과하지 않습니다.

| 검사 | 내용 | 기준 |
| --- | --- | --- |
| 덮음(recall) | 가이드 글자의 잉크를 크레파스 선이 얼마나 덮었는지 (허용 폭 ≈ 글자칸 너비의 8%) | 70~74% (백지 단계 66~68%) |
| 구역(zone) | 글자 상자를 3×3으로 나눠, 잉크가 있는 구역을 모두 채웠는지 — 받침이나 모음을 통째로 빼면 걸립니다 | 구역마다 50~55% |
| 벗어남(precision) | 크레파스 선이 글자 허용 범위 **밖**에 얼마나 있는지 — 마구 낙서를 걸러냅니다 | 45% 이하 |

- 채점은 **손을 뗀 뒤 0.42초** 뒤에만 합니다. 다음 획을 그리기 시작하면 취소됩니다.
- 5·6단계 백지 칸은 글자를 보여 주지 않고, 그림과 소리만으로 씁니다.

## 도감

- `📕 도감` 에서 1,025마리를 세대별로 보고, 이름이나 번호(`피카츄`, `25`)로 찾을 수 있어요.
- 잡은 포켓몬은 그림과 이름이, 아직 못 만난 포켓몬은 회색 실루엣과 `???` 가 보입니다.
- 한 번에 60마리씩 보여 주고 `더 보기` 로 이어서 봅니다 (휴대폰 데이터를 아끼려고).
- 잡은 포켓몬을 누르면 큰 그림·번호·세대·타입과 울음소리 버튼이 나옵니다.

## 보상

- 이름을 다 쓰면 그 포켓몬이 도감에 담깁니다 (1,025마리 전부 잡을 수 있어요).
- 단계를 깨면 보상 포켓몬이 포켓볼에서 나옵니다
  (토게피 · 블래키 · 나무지기 · 가디안 · 팽도리 · 자시안).
- 별 3개가 기본이고, "다시 쓰기"나 힌트를 많이 쓰면 별이 줄어요.
- 모든 단계를 깨면 전설의 포켓몬 **뮤**가 찾아옵니다.

## 개발

정적 파일만 있습니다. `index.html` 을 열거나 아무 정적 호스팅에 올리면 됩니다.

- `index.html` — 화면 뼈대
- `style.css` — 스타일 (밝은 파스텔·장난감 느낌)
- `pokemon-data.js` — **생성 파일**: 전국도감 1~1025 (이름·세대·타입)
- `data.js` — 단계 규칙, 문제 뽑기, 그림·울음소리 주소
- `app.js` — 따라쓰기 캔버스, 정밀 인식(덮음·구역·벗어남), 채점 시점, 울음소리, 진행 로직, Web Audio 효과음, 한국어 TTS
- `build/build_data.py` — PokeAPI 자료(CSV)로 `pokemon-data.js` 만들기 (`python3 build/build_data.py`)
- `build_standalone.py` — 위 파일들을 합쳐 `standalone.html` 한 파일로 만들기 (`python3 build_standalone.py`)
- `tests/run_tests.py` — Playwright 브라우저 자동 테스트 (`python3 tests/run_tests.py`)
- `tests/live_check.py` — 공개 주소 확인과 화면 캡처 (`python3 tests/live_check.py`)

이름·번호·세대·타입은 [PokeAPI](https://pokeapi.co/) 자료로 확인했고,
이미지는 [PokeAPI 공식 아트워크 스프라이트](https://github.com/PokeAPI/sprites),
울음소리는 [PokeAPI cries](https://github.com/PokeAPI/cries)를 씁니다
(로드 실패 시 스프라이트 → 포켓볼 그림 순서로 대체).

주소 끝에 `#debug` 를 붙이면 `window.__trace` 로 칸 상태·채점 결과·울음소리 상태를 확인할 수 있는 테스트용 도우미가 켜집니다.

> v4에서 저장 키가 `pokemon-hangul-v4` 로 바뀌었습니다. v3(`pokemon-hangul-trace-v3`) 기록이 있으면
> 잡은 포켓몬·별·열린 단계를 그대로 이어받습니다.

> 저장 형식 `ver: 5` 부터는 예전에 세대 칩 때문에 한 세대로 고정되어 저장된 기록을 **한 번만** 전체로 되돌립니다.
> (잡은 포켓몬·별·열린 단계는 그대로 남습니다. 이후에 고른 세대는 다시 열어도 유지됩니다.)
