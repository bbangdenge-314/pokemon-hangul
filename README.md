# 포켓몬 한글 따라쓰기 ✏️

▶ **바로 놀기: https://bbangdenge-314.github.io/pokemon-hangul/**

휴대폰 브라우저에서 열고 "홈 화면에 추가"를 누르면 앱처럼 전체 화면으로 실행됩니다.

포켓몬 그림을 보고, 이름을 소리로 듣고, **손가락으로 이름을 따라 쓰는** 5살 한글 놀이입니다.

- 설치 없이 브라우저에서 바로 실행되는 정적 사이트 (GitHub Pages)
- 포켓몬 그림 + 한국어 TTS 로 이름을 읽어 줘서 글자를 몰라도 놀 수 있어요
- 큰 칸에 손가락(마우스)으로 따라 쓰면, 회색 글자를 얼마나 덮었는지 재서 저절로 완성돼요
- 진행 상황은 브라우저(localStorage)에 저장됩니다

## 노는 방법

1. 포켓몬이 나오고 이름을 읽어 줍니다. 따라 쓸 글자는 노란 칸으로 표시돼요.
2. 칸 안의 회색 글자 위를 손가락으로 따라 긋습니다. 굵은 크레파스 선이 그려져요.
3. 회색 글자를 충분히 덮으면 저절로 "짝짝짝!" 하고 다음 글자로 넘어갑니다.
   조금 그렸으면 `다 썼어요!` 버튼을 눌러도 돼요. (`↺` 다시 쓰기, `🔊` 다시 듣기)
4. 이름을 다 쓰면 포켓몬을 잡아 **나의 포켓몬 도감**에 담깁니다.

## 단계 (쉬운 것 → 어려운 것)

| 단계 | 이름 | 따라 쓰는 글자 | 예 |
| --- | --- | --- | --- |
| 1 | 첫 글자 따라 쓰기 | 이름의 첫 글자 1개 | 뮤 · **푸**린 · **피**카츄 · **꼬**부기 |
| 2 | 두 글자 이름 | 두 글자 이름 전체 | 푸린 · 피츄 · 야돈 · 두두 · 팬텀 |
| 3 | 빈칸 따라 쓰기 | 이름에서 빠진 글자 | 피카[츄] · 꼬부[기] · 고라파[덕] |
| 4 | 세 글자 이름 | 세 글자 이름 전체 | 피카츄 · 파이리 · 이브이 · 망나뇽 |
| 5 | 네 글자 도전! | 네 글자 이름 전체 | 이상해씨 · 라프라스 · 고라파덕 · 개굴닌자 |

각 단계는 포켓몬 6마리로 이루어져 있고, 앞 단계를 깨야 다음 단계가 열립니다.

## 보상

- 이름을 다 쓰면 그 포켓몬이 **도감**에 담깁니다 (25마리).
- 단계를 깨면 보상 포켓몬이 포켓볼에서 나옵니다 (삐삐 · 토게피 · 쥬쥬 · 메타몽 · 리자몽).
- 별 3개가 기본이고, "다시 쓰기"나 "조금만 더" 안내가 많았던 단계는 별이 줄어요.
- 모든 단계를 깨면 전설의 포켓몬 **뮤**가 찾아옵니다.

## 보호자 메뉴

홈/지도 화면의 `보호자` 버튼에서

- 소리 끄기 / 켜기
- 전체 단계 열기 (단계 잠금 해제)
- 진행 기록 지우기

## 개발

정적 파일만 있습니다. `index.html` 을 열거나 아무 정적 호스팅에 올리면 됩니다.

- `index.html` — 화면 뼈대
- `style.css` — 스타일
- `data.js` — 학습 데이터(단계·문제·포켓몬 이름/번호)
- `app.js` — 따라쓰기 캔버스, 덮은 정도 계산, 진행 로직, Web Audio 효과음, 한국어 TTS
- `build_standalone.py` — 위 파일들을 합쳐 `standalone.html` 한 파일로 만들기 (`python3 build_standalone.py`)

포켓몬 이미지는 [PokeAPI 공식 아트워크 스프라이트](https://github.com/PokeAPI/sprites)를 사용하며, 로드에 실패하면 스프라이트 → 포켓볼 그림 순서로 대체됩니다. 이름과 번호는 PokeAPI 의 한국어 명칭으로 확인했습니다.

주소 끝에 `#debug` 를 붙이면 `window.__trace` 로 칸 상태를 확인할 수 있는 테스트용 도우미가 켜집니다.
